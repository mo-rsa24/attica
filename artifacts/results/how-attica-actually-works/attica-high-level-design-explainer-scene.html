How to read the lines

A solid line is a request that waits for an answer. A dashed line is asynchronous. A dotted line only carries traffic when a setting turns it on.

What is not drawn

Stripe appears only as comments in vendors/views.py and as an MCP for future work, so it has no box. There is no Celery, no object storage and no CDN.

The booking-request write path stores its notification row and never pushes it to the channel layer (scheduling/services.py, _create_in_app_notification), so no line runs from the worker to Redis.

node-websocket/ holds only node_modules and a lockfile, so it is not a running component.
