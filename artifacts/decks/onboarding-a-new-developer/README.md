# Onboarding a new developer: the decks

Two Marp decks that carry the reasoning behind the setup guides: why each step exists, rather than
what to type. The guides themselves are in
[../../notes/onboarding-a-new-developer/](../../notes/onboarding-a-new-developer/).

## What is in here

Two slide decks, in Marp markdown. Preview either with
`npx @marp-team/marp-cli@latest <file> --preview`.

## The decks

### backend-setup

**What it shows**

The backend setup sequence as slides, with the reason behind each step: why a virtual environment,
why Redis before Django, why an ASGI server.

**How we got this**

Generated by `/progress-brief` in novice mode from the scope's own source documents, then corrected
by hand. The title slide originally said Django 5.1; it is 5.2.3.

**What it cannot say**

It has not been presented to anybody, so nothing here has been tested against a real audience's
questions.

### frontend-setup

**What it shows**

The same for the frontend: Node, the dev server, the proxy, and how the frontend reaches Django.

**How we got this**

The same route, from the same source documents.

**What it cannot say**

It inherits the guides' incomplete account of the two HTTP clients.
